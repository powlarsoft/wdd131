1. Site Name

3Core Tech

Building Intelligent Solutions for Africa.

The name 3Core Tech was selected to represent a modern technology company built around several major technology areas. “3Core” suggests a strong foundational core of expertise, while “Tech” clearly signals the company’s focus on technology solutions.

The name reflects the company’s umbrella approach to Artificial Intelligence, Software Development, Robotics, Solar Technology, Smart Technology, Business Automation, and GPS & Fleet Technology. It is short, memorable, and suitable for a professional technology business based in Nigeria.

Official business name registered with the Corporate Affairs Commission: 3CORE TECH (Registration No. 9706062).

Domain concept: 3coretech.ng (availability verified for this student project; no domain has been purchased).

2. Site Purpose

The 3Core Tech website introduces a Nigerian technology company that develops and provides practical technology solutions for individuals and businesses. Its focus areas include Artificial Intelligence, Software Development, Robotics, Solar Technology, Smart Technology, Business Automation, and GPS & Fleet Technology.

The site serves potential customers such as small business owners, entrepreneurs, organizations, and technology partners. Visitors can learn what 3Core Tech does, explore its major technology areas and planned services, view selected project concepts, understand the company’s vision, and contact the team.

The website is primarily an informational business presence. It is not a full e-commerce platform. Contact is available via email (3core.ng@gmail.com), a contact form, and the registered business address in Lagos.

In addition to serving real visitors, the site demonstrates skills learned in WDD 131: valid HTML, CSS, responsive design, JavaScript, accessibility, SEO basics, and professional development practices.

3. Scenarios

The following scenarios represent common questions visitors may have when arriving at the site:

Scenario 1

What AI and software solutions does 3Core Tech provide for businesses?

A small business owner or entrepreneur visits the site looking for AI assistants, chatbots, business process automation, custom applications, or related software services. They want a clear overview of the technology areas and service categories offered.

Scenario 2

How can I contact 3Core Tech about a technology project?

A visitor has reviewed the services and project concepts and wants a simple, reliable way to reach the company. They expect to find an email address, a contact form, and basic company information so they can discuss a potential project.

Scenario 3

What technology concepts or initiatives is 3Core Tech exploring?

A visitor interested in innovation wants to see examples of the kinds of projects and technology concepts the company is developing or planning, such as AI tools, automation systems, or smart technology solutions.

Heading Font — Poppins

8. JavaScript Implementation Plan

JavaScript will be used purposefully to meet every WDD 131 requirement while remaining natural to the site. All dynamic strings will be created with template literals. Code will live in an external file (scripts/site.js).

Planned Features

  • Mobile navigation toggle — event listener, DOM class manipulation (all pages)
  • Dynamic copyright year — DOM update in footer (all pages)
  • Services data — array of objects stored in JavaScript; rendered with map or forEach and template literals
  • Service filtering — filter buttons use event listeners, filter array method, and conditional logic to show matching cards
  • Projects data — separate array of objects; dynamically generated cards using template literals and array methods
  • Contact form — submit event listener, form validation with conditional branching, DOM feedback messages, and meaningful use of localStorage (e.g. remember visitor name/email on return visits or store a short confirmation)

Requirement Coverage

  • More than one function
  • DOM element selection and modification
  • Event listeners and event handling
  • Conditional branching
  • Objects and arrays
  • Array methods (map, filter, forEach)
  • Template literals exclusively for output strings
  • localStorage with a practical purpose

9. Additional Planning Notes

Responsive Design

Mobile-first CSS using Flexbox and Grid. Layouts will adapt cleanly across mobile portrait, mobile landscape, tablet, and desktop. Navigation collapses to a menu button on small screens.

Accessibility

  • Semantic HTML5 throughout
  • Proper heading hierarchy
  • Form labels associated with controls
  • Sufficient colour contrast
  • Keyboard-accessible controls and visible focus states
  • Meaningful alternative text for images
  • Clear link and button text

Images

  • Official 3Core Tech logo (icon and full versions)
  • All images optimised for web
  • Lazy loading (loading="lazy") on appropriate images
  • Descriptive alt attributes

References

  • A dedicated references.html page lists all external resources (fonts, icons, images, etc.)
  • The References page is linked from the footer of every page on the site

Performance & Professional Practice

  • External CSS and JavaScript files
  • No unnecessary libraries or frameworks
  • Valid, clean, original code (no templates or site builders)
  • Hosted in the wdd131 GitHub Pages repository inside the project folder
